# Mockups

Mockups de las vistas del sistema, con las direcciones visuales de [`identidad_visual.md`](../identidad-visual/identidad_visual.md) §5.

## Vistas

Todas las vistas usan la versión definitiva, **Escudo UC con la paleta FaCyT** (la versión E de [`identidad_visual.md`](../identidad-visual/identidad_visual.md) §5.1): la distribución de C, con riel de íconos, encabezado editorial con el escudo e IBM Plex Sans + Plex Mono, y los colores de la FaCyT. La eligió el equipo el 28/10/2026. Las versiones A a D quedaron descartadas.

La bandeja de aprobación (15) se rediseñó el 28/10/2026 para que tenga un solo scroll. La lista va agrupada por prioridad y crece con la página, el detalle queda fijo al costado y los filtros se acomodan en varias líneas. En el teléfono, la lista y el detalle son dos pasos.

## Cómo se ven

Abre `index.html` de cada carpeta en el navegador. La barra superior cambia:
- el ancho, entre escritorio y teléfono de 390 px;
- el tema, entre el del sistema, claro y oscuro;
- los controles propios de cada vista, como el estado con error del inicio de sesión o el rol del inicio.

## Cómo se regeneran

La fuente está en `_fuente/`. Allí están el HTML de cada vista y los estilos y el script comunes, en `compartido/`. Después de editar la fuente, corre:

```bash
python -I docs/mockups/_fuente/construir.py
```

El script arma cada carpeta de vista y copia los logos oficiales desde `docs/identidad-visual/logos/` sin modificarlos.

Los datos que aparecen (proyectos, montos, insumos, personas) son de ejemplo, coherentes con el seed del README. No son datos reales.
