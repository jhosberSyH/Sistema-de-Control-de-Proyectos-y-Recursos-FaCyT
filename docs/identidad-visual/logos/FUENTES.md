# Fuentes de los logos

Fecha de descarga de todos los archivos: 27/10/2026.

Los archivos se guardaron tal como los sirve cada sitio, sin redibujar, recortar ni convertir. Solo se les cambió el nombre. El SHA-1 permite comprobar que el archivo no se ha modificado.
